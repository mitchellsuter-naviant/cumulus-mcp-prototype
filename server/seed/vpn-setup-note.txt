Quick VPN setup notes for the engineering team.

1. Install the corporate VPN client from the self-service portal.
2. Sign in with SSO; approve the MFA prompt.
3. Choose the region closest to you for lowest latency.
4. If DNS fails after connecting, toggle "Use VPN DNS" in the client settings.

These are informal notes; the security team's standard wins if anything conflicts.
